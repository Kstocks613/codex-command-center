# Product Strategy Skill

## Purpose

Turn market pain into an MVP people can understand and test.

## Checklist

- [ ] Define target buyer
- [ ] Define urgent pain
- [ ] Define promise
- [ ] Define smallest paid/free MVP
- [ ] Define what not to build
- [ ] Define validation plan
- [ ] Create landing page structure
- [ ] Create first sprint scope

## Output Format

```markdown
# Product Strategy Brief

## Buyer
## Pain
## Promise
## MVP
## Not Included Yet
## Validation Plan
## Landing Page Angle
## First Sprint
```

## Failure Modes

- Building a platform before a wedge.
- Targeting everyone.
- Optimizing for features instead of demand.
