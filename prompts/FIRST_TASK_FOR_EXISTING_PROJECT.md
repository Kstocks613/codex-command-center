# First Task for an Existing Project

Use this when the kit has been copied into an existing repo.

```markdown
This repository now contains the Codex Command Center template.

Read `AGENTS.md`, `00_NEW_PROJECT_LAUNCH_PROTOCOL.md`, `START_HERE.md`, and the `.agents/skills` directory.

Run the New Project Launch Protocol for this specific project.

Do not code yet. Do not scaffold a sample product. Treat any project idea or "build" request as raw intake until the launch protocol and sprint approval gate are complete.

Your first deliverables are:

1. `PROJECT_CONTEXT.md`
2. `REQUIRED_DOCUMENTS.md`
3. `PROJECT_BRIEF.md`
4. `MISSING_INFO.md`
5. `INTEGRATIONS_TO_CREATE.md`
6. `ENVIRONMENT_SETUP.md`
7. `AGENT_ROSTER.md`
8. `FIRST_SPRINT_PLAN.md`
9. `APPROVAL_POLICY.md`
10. `TASK_LOG.md`
11. `DECISION_LOG.md`
12. `COUNCIL_REPORT.md`

Ask me for relevant documentation, URLs, screenshots, accounts, APIs, research files, constraints, and decisions.

Then build the research/workstream plan, run Council review for strategic decisions or record why it is not required, propose the smallest useful first sprint, and ask for sprint approval before implementation.
```
