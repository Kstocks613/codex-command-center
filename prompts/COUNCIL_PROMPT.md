# AI Council Prompt

Use this when a decision is strategic, expensive, uncertain, architectural, or when the user says "council this."

## Question

[Insert the exact question here.]

## Context

[Insert only the context needed to decide.]

## Advisors

Run five independent advisor passes.

### 1. The Contrarian
Look for what is wrong, risky, naive, or assumed.

### 2. The First Principles Thinker
Reduce the problem to fundamentals. Reframe if the question is wrong.

### 3. The Expansionist
Look for leverage, upside, scalability, automation, and hidden opportunity.

### 4. The Outsider
Think like the customer, user, buyer, stakeholder, or non-technical operator.

### 5. The Executor
Focus on what can be done now, what will unblock progress, and what can be tested.

## Peer Review

After the five advisors answer, review:

1. Which response is strongest?
2. Which response has the biggest blind spot?
3. What did all five responses miss?
