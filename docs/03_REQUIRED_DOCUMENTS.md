# Required Documents

Codex Manager should create or request these documents before serious execution.

## Always Useful

| Document | Purpose | Required Before Coding? |
|---|---|---|
| `PROJECT_BRIEF.md` | Defines goal, user, constraints, success | Yes |
| `MISSING_INFO.md` | Tracks blockers and questions | Yes |
| `APPROVAL_POLICY.md` | Records what Codex may do automatically | Yes |
| `DECISION_LOG.md` | Records major decisions | Yes |
| `TASK_LOG.md` | Tracks execution | Yes |
| `FIRST_SPRINT_PLAN.md` | Prevents endless planning | Yes |
| `INTEGRATIONS_TO_CREATE.md` | Tracks accounts/APIs/plugins | Usually |
| `ENVIRONMENT_SETUP.md` | Install/run/test/deploy commands | Usually |
| `AGENT_ROSTER.md` | Defines specialist agents | Usually |
| `COUNCIL_REPORT.md` | Strategic decision synthesis | When needed |
