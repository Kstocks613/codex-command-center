# Integrations Matrix

Codex Manager should create `INTEGRATIONS_TO_CREATE.md` using this structure.

```markdown
| Category | Tool / Service | Why Needed | Required Now? | User Must Create Account? | Secrets Needed | Default Recommendation | Approval Needed? |
|---|---|---|---|---|---|---|---|
```
